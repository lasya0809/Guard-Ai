# GuardAI — AI Content Safety Tool 🛡️

## 🌐 Live Demo
👉 https://web-production-8d4af.up.railway.app

## 📌 About
GuardAI analyzes any text and instantly classifies it as safe,
spam, toxic, or offensive using AI. Shows confidence scores
through live pie and bar charts.

## 🛠️ Tech Stack
| Layer | Technology |
|---|---|
| Backend | Python, Flask |
| AI Model | Llama 3.3 70B |
| AI Provider | Groq API |
| Frontend | HTML, CSS, Chart.js |
| Deployment | Railway |

## ⚙️ Setup
1. Clone: `git clone https://github.com/lasya0809/Guard-Ai`
2. Install: `pip install -r requirements.txt`
3. Set key: `export GROQ_API_KEY=your_key_here`
4. Run: `python app.py`
5. Open: `http://localhost:5000`
